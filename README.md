# 웨체스터제일교회 온가족 성경통독

2026-2027년 온가족 성경통독을 위한 스마트폰 설치형 웹앱입니다.

## 주요 기능

- 성경 66권, 총 1,189장 통독 기록
- 권별/장별 완료 표시와 전체 진행률
- 오늘 통독한 장 수와 날짜별 통독 달력
- 날짜를 선택해 해당 날짜에 읽은 성경 장 확인
- 성경 전체 완독 횟수 누적 및 `1독 완료`, `2독 완료` 배지
- 다음 회독을 시작해도 이전 회독의 날짜별 기록 보존
- 날짜에 따라 매일 새롭게 바뀌는 오늘의 말씀
- 개인 스마트폰에 읽은 기록 자동 저장
- 구약/신약 탐색
- 웨체스터제일교회 로고와 비전
- 아이폰 및 안드로이드 홈 화면 설치

## GitHub Pages 배포

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 저장소의 `Settings` > `Pages`로 이동합니다.
3. `Source`에서 `GitHub Actions`를 선택합니다.
4. `Actions` 메뉴에서 `성경통독 앱 배포`가 완료될 때까지 기다립니다.
5. `Settings` > `Pages`의 `Visit site`를 눌러 앱을 엽니다.

자세한 안내는 함께 제공된 `GitHub에 올리는 방법.txt`를 확인하세요.

## 말씀 메모와 한 줄 감사

- 하단 **메모·감사** 또는 홈 화면 바로가기에서 날짜별로 작성합니다.
- 하루에 말씀 구절, 최대 10,000자의 메모, 최대 300자의 한 줄 감사를 보관합니다. 입력 즉시 이 브라우저에 저장됩니다.
- 처음 작성한 시각과 마지막 수정 시각을 표시합니다. 지난 기록은 날짜 역순으로 보며 월/내용으로 검색할 수 있습니다.
- 달력의 연필 표시는 해당 날짜에 메모 또는 감사 기록이 있다는 뜻입니다. 달력에서 선택한 날짜의 메모로 이동할 수 있습니다.
- 통독 회차를 바꾸거나 통독 진도를 초기화해도 메모는 삭제되지 않습니다. 메모 삭제는 날짜별 확인 후 따로 수행합니다.
- 백업 v2에는 통독 기록과 메모/감사가 함께 포함됩니다. 같은 언어의 v2 복원은 모두 교체하며, v1 복원은 통독만 교체하고 기존 메모를 유지합니다.
- 데이터는 자동 동기화되거나 교회로 전송되지 않습니다. 기기 변경/브라우저 데이터 삭제 전에 백업하세요. JSON 백업은 암호화되지 않으므로 안전하게 보관하세요.
- 저장 실패 시 경고를 표시하고 현재 작성 내용은 화면에 유지합니다. 이 상태에서도 백업 버튼은 메모를 파일로 저장할 수 있습니다.

검증: `npm test` (날짜, 메모 수정/검색, 백업 v1/v2 호환성, 잘못된 파일 차단, 저장 실패 롤백).
